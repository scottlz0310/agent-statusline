# 設定 TUI の実機確認（Ubuntu）

フェーズ 2（トラッカー #84）の実機確認のうち、Ubuntu の結果。Windows の結果は `config-tui-verification-windows.md`。ここでは、Windows で確認できなかった項目を中心に確認した。

## 環境

| 項目 | 内容 |
|---|---|
| 日付 | 2026-10-17 |
| OS | Ubuntu 26.04.1（GNOME Shell 50.1、Wayland のみ。GNOME 50 は X11 セッションを廃止している） |
| 端末 | **Xvfb（仮想 X サーバー）上の `xterm`**（`DejaVu Sans Mono`、120×40）。GNOME Terminal ではない |
| 対象 | `main`（`3c45cd1`）のリリースビルド（`agent-statusline` 0.4.2） |
| 操作 | `xdotool`（XTEST）でキー・マウスを注入し、`import -window root` で撮影して確認 |

実画面（Wayland）への入力注入は、フォーカス中の別の窓に入力が届くため行わず、隔離した Xvfb だけで操作した。確認用の設定は 3 種類。`config-long`（`$model` を 120 行並べた設定。行番号の桁数の確認用）、`config-short`（短い設定。競合・マウスなど）、`config-conflict`（競合の確認用の複製）。

## 結果

凡例: ○ 問題なし／△ 動作するが気づいた点あり／－ 未確認（理由を併記）

### Windows で確認できなかった項目

| 項目 | 結果 |
|---|---|
| 3 桁の行番号（100 行以上） | ○ 87〜120 行で、桁が増えても行番号が右揃えのまま、選択位置の反転も正しい |
| 競合時の `d` | ○ 外部で書き換えた後に `s` で競合になり、`d` で「ディスク上の今の内容 → 下書き」の差分（`+` 下書きで足した行、`-` 外部で足した行）が出る |
| `Shift` でのテキスト選択（マウス有効時） | ○ 端末側の選択になり、アプリへのマウス入力は無い（アプリの出力 0 バイト）。`xterm` での確認のみ |
| ポインター移動で画面がちらつかない | ○ 60 回移動して、アプリの描画出力は 0 バイト（キー 1 回の全体再描画は約 7.8 KB）。イベントがアプリに届いたことの独立した確認はしていない |
| 異常終了（panic）時のマウスキャプチャの解除 | ○ 4 秒後に別スレッドで panic する検証用ビルド（リポジトリには入れない）で確認。終了コード 134（abort）、panic メッセージは通常画面に出て、その後のクリック・ホイールで `^[[<…` が出ない |

panic の確認は、対照実験で方法の妥当性を担保した。`SIGKILL`（フックが走らない）で終了させると、キャプチャが残り、クリック・ホイールで `^[[<0;36;17M` などが端末に出る。panic ではこれが出ない。

### そのほか

| 項目 | 結果 |
|---|---|
| 終了時のマウスキャプチャの解除（`q` → `y`、終了コード 0） | ○ 終了後のクリック・ホイールで `^[[<…` が出ない |
| 部品一覧のクリック（フォーカス移動 → 選択）、ホイール、配置領域のクリック（フォーカス移動） | ○ |
| 全体の描画（絵文字、日本語、枠線、色） | ○ |
| 極端に小さい端末（640×400 → 40×16 px）へのリサイズ | ○ panic せず、元のサイズにも戻る |

気づいた点: 部品を選ぶとプレビューの行が 1 行増えて画面全体が 1 行ずれる。同じ座標をもう一度クリックすると、隣の項目に当たる（「選択済みの項目をもう一度クリックして実行」が意図どおりにならない場面がある）。仕様による動きで、Windows でも起きうる。

## 確認できなかった項目

- GNOME Terminal 固有の見え方（`blue` の見本の濃さ、絵文字の幅）。端末は `xterm` のみ。
- `Shift` でのテキスト選択の、GNOME Terminal での動き。
- IME の変換ウィンドウの位置（[#94](https://github.com/scottlz0310/agent-statusline/issues/94)）。Xvfb では確認できない。

## 確認の方法についての注記

- Ubuntu 26.04 は X11 セッションがなく、Wayland のまま実画面の `xterm` に `xdotool` で注入しても、入力はフォーカス中の別の窓（作業中の端末）に届く。必ず `DISPLAY` を Xvfb（`:99`）にして操作すること。
- `pgrep -x` はプロセス名が 15 文字に切られる（`agent-statuslin`）。
