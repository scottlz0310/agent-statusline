## 確認できなかった項目（Ubuntu での確認時に行う）

- `Shift` でのテキスト選択（マウス有効時）
- ポインター移動で画面がちらつかないこと
- 3 桁の行番号（100 行以上の設定）
- 競合時の `d`
- 異常終了時のマウスキャプチャの解除（panic 時）

## 確認の方法についての注記

- windows-mcp の `Shortcut` ツールは、`space` を送ってもアプリに届かなかった（`Type` で空白を送ると動作した）。アプリ側の不具合ではなく、ツールの制約と判断した。
- Windows Terminal の起動は、`wt.exe -w new --title <名前> pwsh -NoExit -File <スクリプト>` で行った。
